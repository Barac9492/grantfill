# GrantFill

**핵심만 쓰면, 반복은 채워집니다.** 정부 출자사업(모태펀드 등) GP 지원서 작성 도구.

## 왜 이렇게 만들었나

지원서 자동화가 실망스러운 이유는 대개 **반복되는 부분을 진공 상태에서 따로 생성**하기 때문이다.
그러면 결과물이 일반적(generic)이라 결국 다시 손봐야 하고, 절약이 사라진다.

GrantFill은 순서를 뒤집는다:

1. 당신은 **Core**(창의적 핵심 — 논지·팀·차별점·숫자)만 한 번 쓴다.
2. 반복되는 모든 섹션은 그 Core를 **유일한 근거**로 생성된다 → 자동으로 일관성 확보.
3. Core에 없는 사실은 지어내지 않고 `[확인 필요: ...]`로 표시한다.

당신의 시간은 오직 Core(창의적인 부분)에만 쓰인다.

## 로컬 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

API 키는 화면 상단에 붙여넣으면 되고(브라우저 localStorage에만 저장), 서버에 `ANTHROPIC_API_KEY`를 설정해도 된다.

## 배포 (Vercel)

이 저장소를 Vercel에 임포트하면 끝이다. 별도 설정 없이 동작한다.
서버에 키를 두고 싶으면 환경변수 `ANTHROPIC_API_KEY`만 추가하면 된다.

## 스택

Next.js 14 (App Router) · React 18 · Anthropic SDK. 데이터베이스 없음, 상태는 브라우저에만 저장.

## 한계 (솔직히)

- 이 도구는 **당선되는 지원서**를 보장하지 않는다. 반복 노동을 줄여 창의적 부분에 집중하게 할 뿐이다.
- 심사 통과의 핵심(당선 사례 코퍼스, 심사 기준)은 여전히 사람의 몫이다.
